# Portale Carbon WastePrint

Portale operativo del Programma Carbon WastePrint® — certificazione dei crediti di
carbonio derivanti dalla gestione virtuosa dei rifiuti urbani.

Programma di Fondazione Operate, validato da RINA Services SpA ai sensi della
ISO 14064-2:2019.

## Cos'è

Strumento gestionale multi-attore che accompagna le pratiche lungo le sei fasi
ufficiali del Programma (Giorno 0 → Giorno 150), con viste e permessi distinti per:

- **Soggetto Promotore del Progetto** — comuni, enti locali, soggetti gestori
- **Fondazione Operate** — regia interna del Programma
- **Ente di Validazione e Verifica** — RINA Services SpA

## Tecnologie

- **React + Vite** — interfaccia
- **Supabase** — database, autenticazione e archivio documenti (in collegamento)
- **GitHub + hosting** — codice e pubblicazione online

## Avvio in locale

```bash
npm install
cp .env.example .env   # inserire i valori Supabase
npm run dev
```

## Stato

In sviluppo. Impalcatura iniziale e flusso ufficiale impostati; backend e
dashboard per ruolo in lavorazione.
